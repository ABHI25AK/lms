2. Book Catalogue & Copies Catalogue Core
GET /api/books/

List books with search & category filtering. Parameters: ?search=, ?category=, ?available=true.

GET /api/books/<id>/

Get detailed bibliographic information with physical copy accession records.

GET POST /api/copies/

Physical copy inventory endpoints. POST restricted to Librarian.

3. Circulation & Loan Issue Librarian Only
POST /api/loans/issue/

Checks borrowing limits and FIFO queue priority, creates loan, locks physical copy, and collects security deposit.

// Request Payload:
{
  "student_id": 2,
  "accession_number": "CS-2025-0105",
  "payment_mode": "CASH",
  "notes": "Issued for Core Lab Assignment"
}
4. Deposit-Linked Return & Settlement Critical Financial Engine
POST /api/loans/<id>/return/

Processes return date, calculates overdue days, adjusts against held deposit, and re-allocates copy to next reservation.

// Request Payload:
{
  "return_date": "2026-10-21",
  "disburse_refund": true,
  "collect_fine": true,
  "notes": "Book returned in pristine condition."
}

5. FIFO Reservation Queue Queue Manager
GET POST /api/reservations/

Students view their own queue positions or request new reservations. Admins view global queue.

6. Financial Ledger Auditable Records
GET /api/finances/

Audit trail of security deposits collected, fines deducted, and cash refunds disbursed.

7. Real-Time Dashboard & Analytics Chart.js Feeds
GET /api/dashboard/stats/

Returns dynamic chart series and aggregated metrics for the authenticated user's role.
